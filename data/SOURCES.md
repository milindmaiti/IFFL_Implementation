# Dataset sources

The eight benchmark instances bundled here are redistributed for reproducibility. They
were assembled and published by the **Fair-FL** project:

> E. Rivera-Bustos et al., *Fair-FL*. https://github.com/EmmiRiv/Fair-FL

Each is in turn adapted from a public upstream source:

| files | upstream |
|---|---|
| `adult-500-20*.csv`, `adult-429-65*.csv` | Becker, B. & Kohavi, R. (1996). *Adult*. UCI Machine Learning Repository. https://doi.org/10.24432/C5XW20 |
| `bank-500-20*.csv` | Moro, S., Rita, P. & Cortez, P. (2014). *Bank Marketing*. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306 |
| `data49UFLP.xlsx`, `data88UFLP.xlsx` | Snyder, L. V. & Daskin, M. S. — data sets for reliability models for facility location. https://coral.ise.lehigh.edu/larry/research/data-sets-for-reliability-models-for-facility-location-the-expected-failure-cost-case/ |
| `synth-*.csv` | Synthetic, generated by the Fair-FL project. |

## File conventions

Each dataset is a pair: `<name>.csv` holds clients, `<name>-fac.csv` holds candidate
facilities.

* `d1 … dk` are the numeric coordinates distances are computed over. Adult and Bank are
  z-scored; the synthetic sets are raw 2-D points.
* `c1 … ck` on a client file are categorical attributes (race, sex, job, …), kept for
  analysis. They are *not* used by any algorithm here, which enforces individual rather
  than group fairness.
* `c` on a *facility* file is the opening cost, not a category. Only the synthetic
  facility files carry one; costs for Adult and Bank are synthesized (see
  `iffl/costs.py`).
* `adult-500-20` and `bank-500-20` are whitespace-delimited; the rest are
  comma-delimited. The loader sniffs the separator.

The two `.xlsx` workbooks put column headers on row 2 and data from row 3, with columns
`index, demand, emerg cost, failable, fixed cost, lat, lon, …`. Clients and facilities
are the **same** point set in both.

These files are read-only inputs. Generated radii and opening costs are written to
`instances/` as sidecars; nothing here is modified.
